Design note for the reviewer:
- Rate-limit semantics are sliding-window over the timestamp list (the card's mandated structure),
  so the block lifts as failures age past 600s. For clustered brute-force this equals "600s from
  the last failure"; deliberately spread-out failures are not a brute-force threat and are untested.
- list_events orders by (created_at DESC, id DESC) because now_iso() is second-precision; id DESC
  makes same-second ordering deterministic.
