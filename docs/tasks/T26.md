## Goal

An employer can enter an optional external meeting URL when creating an interview slot. After
booking, the candidate can select **Join interview** from My applications or the booked interview
page. The employer who owns the job sees the same link in the applicant's booking row.

## Requirement

The brief's FP-SCHED-2 requires a successful booking to be visible to both the candidate and the
owning employer. P2 approved the external link as an ungraded enhancement. Show it only on
authorized booking views and only when a link exists. A slot without a link remains bookable.

## Contract

Implement the `create_slot` and booking view additions recorded by CC03. Reuse the existing slot
creation form, candidate application pages, and employer applicants route. Use the existing
candidate and employer ownership checks before rendering a link. Candidate slot selection and
booking confirmation show the time only. A booking's link remains available to the same parties
if its application status changes and the booking remains associated with the application.

## Steps

1. Write and run failing tests for link validation and visibility before implementation.
2. Add an optional URL field to the employer slot form. Trim surrounding whitespace and treat an
   empty value as `NULL`. Accept absolute `https://` URLs with a valid host. Return the existing
   field validation error for missing hosts, malformed URLs, other schemes, or embedded credentials.
3. Read the URL through the existing booking join on candidate pages. After the employer job
   ownership check, load links for the job's booked applications in one query and key them by
   application ID. Render escaped links through Jinja on the authorized pages.
4. Run the gate and scope check, then hand off for peer review.

## Tests

- `tests/unit/test_sched_slots.py::test_create_slot_with_meeting_url` checks storage of a valid
  HTTPS URL, blank or omitted input, and rejection of invalid forms without creating a slot.
- `tests/unit/test_sched_booking.py::test_meeting_link_visible_after_booking_to_candidate_owner`
  checks absence on the selection and confirmation pages, presence on the candidate's booked
  detail and application list, and denial to another candidate. A booking without a URL has no
  Join interview link.
- `tests/unit/test_emp_applicants.py::test_meeting_link_visible_only_to_owning_employer` checks
  that only the employer who owns the job sees the link in its booked applicant row.
