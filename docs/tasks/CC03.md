# CC03 · Contract change for interview meeting links

| Phase | Lane | Depends on | Joins lanes | Status |
|---|---|---|---|---|
| Post-submission | Integration (P2) | T12, T16, T17 | yes | TODO |

## Goal

Store one optional meeting URL per employer-owned interview slot. Fresh and existing SQLite
databases must support the same schema before T26 starts. Existing slots and bookings retain their
IDs and relationships, with `NULL` for the new field.

## Requirement

The brief's FP-SCHED-2 requires a successful booking to be visible to the candidate and the owning
employer. The meeting link is a P2-approved, ungraded enhancement. The booking and availability
rules in FP-SCHED-1 through FP-SCHED-3 still apply.

## Contract

- Add nullable `meeting_url TEXT` to `interview_slots` and mirror it in the data model.
- Record the T26 `create_slot` signature and authorized view data in `07-CONTRACTS.md` before T26
  begins. The signature adds a keyword-only `meeting_url: str = ""` argument. Candidate booking
  objects gain a nullable `meeting_url`. The employer applicants route supplies an
  `interview_links` mapping of application ID to URL. The `list_applicants` result retains its
  existing keys and booking shape.

## Steps

1. Add a failing database regression test for upgrading an existing database with a saved booking.
2. Extend the fresh schema and implement an additive startup upgrade for an existing initialized
   database. Check for the column before altering the table and recheck under a SQLite write
   transaction so concurrent starts can safely retry. Preserve the existing fresh, empty, and
   partial database handling.
3. Document the schema and the T26 contract. Run the gate and scope check before peer review.

## Tests

- `tests/unit/test_db.py::test_interview_meeting_url_schema_upgrade` checks that app startup adds
  the column to an existing database, preserves a saved slot and booking, defaults the link to
  `NULL`, and preserves a saved URL across another startup. Verify the column also exists on fresh
  initialization.
