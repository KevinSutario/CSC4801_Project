# CC03 · Contract change for interview slot notes

| Phase | Lane | Depends on | Joins lanes | Status |
|---|---|---|---|---|
| 6 | Integration (P2) | T12, T16, T17 | yes | READY |

## Goal

Fresh and existing SQLite databases support one optional plain-text note per employer-owned
interview slot. Existing slots and bookings keep their IDs, times, and relationships.

## Requirement

FP-SCHED-2 requires a successful booking to be visible to the candidate and owning employer.
Notes are a P2-approved enhancement to the booking experience. T27 supplies the user-facing
behavior.

## Contract

Add `interview_slots.interview_note TEXT NOT NULL DEFAULT ''`. At startup, add the missing
column for initialized databases in a write transaction and recheck after acquiring the lock.
Preserve the existing handling of empty and partial databases. Record T27's slot and booking
view contracts in `07-CONTRACTS.md`.

## Tests

- `tests/unit/test_db.py::test_interview_note_upgrade_preserves_bookings` verifies that the
  upgrade preserves bookings and stored notes across startup.
