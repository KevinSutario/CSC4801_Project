## Goal
A candidate sees every job ranked for them, each with its score and which skills matched and
which are missing.

## Requirement
FP-CAN-2: recommendations preserve fields and rank all jobs. Rule text (brief section
"3. Candidate workflow", FP-CAN-2 "Recommendations"):
> A candidate dashboard **MUST** list all current (not deleted) jobs with a visible match score and sort them from highest to lowest score. The dashboard **MUST** include the job title, employer/company, required skills, and a way to view the description.

Which fields each card shows (from the quote): "the job title, employer/company, required skills,
and a way to view the description", plus "a visible match score". Order: "from highest to lowest
score", ties by FP-MATCH-1: "case-insensitive job title and then stable job ID". The old default
list (title, company name, location, employment type, salary range or "Not stated", score, matched,
missing) must at least add the full required-skills list; the extra fields are DEFAULT (not in
brief).

Answers for the test bullets:
- Zero-score jobs: "list all current (not deleted) jobs", so a zero-overlap job is present.
- No closed state (D18): jobs have no closed flag, so `list_jobs(conn)` returns every job and the
  dashboard lists them all.
- A candidate with no skills still sees the full ranked list; the "Add your skills" line is a hint
  above the list, never an empty state that replaces it (D15).
- "Candidate and employer views **MUST** call the same implementation." (FP-MATCH-1)

## Contract
```python
def recommend_for(conn, candidate_id: int) -> list[dict]          # rank(skills, list_jobs(conn))
def score_candidate_for_job(conn, candidate_id: int, job_id: int) -> dict   # engine.score for one job
```
Route `matching.recommendations` GET `/candidate/recommendations`, `@role_required("candidate")`.

## Steps
1. Tests first.
2. `recommend_for`: `set(get_profile(conn, candidate_id)["skills"])`, `list_jobs(conn)`, `rank`.
3. `score_candidate_for_job`: `get_job` (NotFound if missing), then `engine.score`.
4. Page: one card per job in the returned order, `score_bar`, "Matched:" and "Missing:" lists,
   link to `/jobs/<id>`. The "Add your skills" hint shows above the full list when the candidate has
   no skills; the no-jobs empty state from `05-UX-FLOWS.md`.
