## Goal
One command resets the app to a known demo state that shows every feature, with the demo accounts
from `docs/plan/12-DEPLOY.md`.

## Owns
- `scripts/seed.py`
- `tests/unit/test_seed.py`

## May read
- `CLAUDE.md`
- `docs/plan/12-DEPLOY.md` (section: Demo data)
- `docs/plan/07-CONTRACTS.md` (all service signatures)
- `app/__init__.py`, `app/db.py`, `tests/conftest.py`

## Steps
1. `scripts/seed.py`: `--reset` deletes the database file (path from the app config, never
   hard-coded), then `init_db()`. Without `--reset` it refuses if the database already has users.
   Then it creates the demo data **through the real services** (`register`, `save_profile`,
   `save_resume`, `save_company`, `create_job`, `create_slot`, `apply`, `set_status`), so demo data
   always obeys the rules. One demo password for all five accounts (documented demo-only in
   INSTALL.md).
2. Data (the mandatory minimum from `12-DEPLOY.md`, FP-DOC-3): five accounts — candidates
   `meilin@demo.keystone` (Python, SQL), `arjun@demo.keystone` (Python), `sofia@demo.keystone`
   (Rust); employers `daniel@demo.keystone` (Harbourline Logistics), `priya@demo.keystone`
   (Tidewater Freight). Jobs: Harbourline "Data Analyst" (Python, SQL); Tidewater "Logistics
   Coordinator" (SQL, Excel); Tidewater "Graduate Trainee" (no skills). Applications: Mei Lin and
   Arjun on Data Analyst both `interviewing`; Sofia on Data Analyst `pending`; Mei Lin on Graduate
   Trainee `accepted`; Sofia on Graduate Trainee `rejected`. Slots: Daniel one future 30-minute
   unbooked slot in `Asia/Hong_Kong`; Priya one in `Europe/London`. T19 may add more jobs after
   these.
3. Seed Mei Lin's resume as raw text: `save_resume(conn, user_id, "Demo resume. Fictional person.")`.
4. Also expose `seed(app)` so `wsgi.py` can seed a new database on first start.

## Tests (`tests/unit/test_seed.py`)
- `seed(app)` on the test app creates exactly 5 users and 3 jobs; applications cover all four
  statuses; two `interviewing` candidates are eligible for Daniel's slot
- the four FP-MATCH-1 example scores come out of `engine.score` on the seeded rows (Mei Lin 100,
  Arjun 50, Sofia 0 on Data Analyst; everyone 100 on Graduate Trainee)
- running it twice without reset refuses and changes nothing
